# FlowCube 通信协议规范

## 1. 概述

本文件定义了 M5Stack Core2 硬件与 FlowCube Web App（通过 Node.js WebSocket 服务器中转）之间的通信协议。

```
[M5Stack] ←→ WebSocket ws://host:3000/ws ←→ [Browser App]
```

所有消息均为 UTF-8 编码的 JSON 字符串。

---

## 2. 握手（连接后第一条消息）

所有客户端（设备端与浏览器端）连接后必须首先发送握手消息，才能进行后续通信。

### 2.1 客户端 → 服务器

```json
{
  "type": "handshake",
  "client_type": "device",
  "device_id": "m5stack-flowcube-01"
}
```

| 字段          | 类型   | 说明                          |
|-------------|------|-------------------------------|
| `type`        | string | 固定值 `"handshake"`          |
| `client_type` | string | `"device"` 或 `"app"`         |
| `device_id`   | string | M5Stack 设备唯一 ID（浏览器端用相同 ID 配对）|

### 2.2 服务器 → 客户端（确认）

```json
{
  "type": "handshake_ack",
  "device_id": "m5stack-flowcube-01"
}
```

---

## 3. 翻转方向事件

### 3.1 M5Stack → 服务器 → App

M5Stack 检测到稳定翻转后发送：

```json
{
  "type": "orientation",
  "device_id": "m5stack-flowcube-01",
  "face": "study",
  "timestamp": 1234567890
}
```

| `face` 值    | 触发条件               | App 行为               |
|-------------|----------------------|----------------------|
| `"idle"`    | 屏幕朝上               | 无操作                 |
| `"study"`   | 屏幕朝下               | 自动进入学习专注模式     |
| `"exercise"`| 左侧朝上               | 自动进入运动专注模式     |
| `"rest"`    | 右侧朝上               | 结束当前专注，显示完成弹窗|
| `"unknown"` | 无法判断姿态            | 忽略                   |

服务器收到后，将消息转发给同一 `device_id` 下注册的 App 客户端。

---

## 4. 心跳（Keepalive）

客户端每 20 秒发送一次 ping，服务器回复 pong。

```json
// 客户端 → 服务器
{ "type": "ping" }

// 服务器 → 客户端
{ "type": "pong", "timestamp": 1234567890 }
```

---

## 5. 错误消息

```json
{
  "type": "error",
  "message": "First message must be a handshake"
}
```

---

## 6. HTTP REST API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 注册账号 |
| POST | `/api/auth/login`    | 登录，返回 JWT |
| POST | `/api/sessions`      | 创建专注会话 |
| PUT  | `/api/sessions/:id/complete` | 完成会话 |
| DELETE | `/api/sessions/:id` | 放弃会话 |
| GET  | `/api/sessions`      | 查询历史会话 |
| GET  | `/api/stats`         | 查询统计数据 |

所有需要认证的接口均需在请求头中携带：
```
Authorization: Bearer <JWT_TOKEN>
```

## 7. M5Stack 翻转姿态说明

```
屏幕朝上 (idle)       屏幕朝下 (study)
    ┌─────┐               ┌─────┐
    │ LCD │               │     │
    │  ↑  │      →→→      │  ↓  │
    └─────┘               └─────┘

左侧朝上 (exercise)   右侧朝上 (rest)
    ┌─┐                     ┌─┐
    │←│          →→→         │→│
    └─┘                     └─┘
```

IMU 阈值：`|axis| > 0.6g` 且连续稳定 8 帧（≈800ms）才触发事件。
